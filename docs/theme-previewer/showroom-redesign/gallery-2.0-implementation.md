# Design Gallery 2.0 implementation

- Replaced the developer toolbar with a compact three-zone editorial header.
- Added catalog-backed theme discovery with current gallery thumbnails.
- Separated curated editions from theme discovery and retained the preset architecture.
- Reframed device controls around Desktop, Tablet and Mobile without pixel readouts.
- Added a persistent contextual dock with theme, edition, premium state, full-demo action and a single “Use this theme” conversion action.
- Preserved signed in-memory preview sessions and clean iframe URLs.
- Synchronized preview language through the in-memory session; no locale or capability is exposed in the URL.
- Added Escape dismissal, semantic popover labels, visible focus treatment and reduced-motion behavior.
- Replaced the NEXA empty hero with an original optimized WebP photograph and theme-specific English, French and Arabic copy.
- Corrected the local preview port map and local filesystem media base.
- Made the white TijaraGO logo prominent and linked it to the public home route.
