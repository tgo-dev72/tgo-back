# Design decisions

- Shell palette: `#0F1117`, `#171A22`, `#2A2E39`, white primary text and restrained secondary text.
- Toolbar: 68px desktop, three functional zones, compact premium badge, one primary conversion action.
- Preview sizes: 1440px desktop, 768px tablet and 390px mobile; iframe content is never scaled.
- Discovery: one popover contains available themes and presets so controls do not compete with the storefront.
- Presets: color/surface swatches provide useful visual recognition without downloading every theme.
- Motion: existing 150–300ms transitions remain and reduced-motion behavior is preserved.
- Media: original synthetic WebP photography is optimized, locally owned and free of competitor branding or claims.
